# Personal Finance Category Icons

个人记账使用的收入与支出分类图标。分类名称和资产路径见 `分类清单.csv`。

每个一级、二级分类适合记录的账单示例见 [分类使用说明](分类使用说明.md)。

![支出分类图标预览](预览-支出.png)

![收入分类图标预览](预览-收入.png)

- 支出：12 个一级分类、123 个二级分类。
- 收入：4 个一级分类、18 个二级分类。
- 每个图标同时提供 SVG 和 512 × 512 透明背景 PNG。
- 分类图标按一级分类、二级分类存放，文件名中的 `/` 改为 `_`。
- 分类名称使用可复用的通用叫法；车辆与子女支出分别列为独立分类。
- 带儿童肖像的 5 个分类同时提供 `(女)`、`(男)` 两套 SVG/PNG；`分类清单.csv` 默认指向女版，男版见 `预览-子女变体.png`。
- 采用透明背景、深色粗描边、奶油色辅色、橙色强调与底部阴影的物件插画风格。一级分类在浅青、暖黄、鼠尾草绿、柔粉、蜜桃和浅紫灰之间分配主色；二级分类从同一套低饱和配色中按物件含义选择颜色。
- `日用家居`、`安全防护`、`乳品烘焙` 三张参考图的造型用于对应分类，颜色按分类配色统一。
- 部分基础造型改绘自 Lucide，相关许可见 [Lucide-LICENSE.txt](Lucide-LICENSE.txt)。
- 新增、调整与删除记录按日期保存在 [docs/changes/](docs/changes/)（每天一份）；造型调整对照预览见 `调整预览.png`。
- 修改分类配色后，运行 `python3 scripts/apply_palette.py` 同步 PNG 与预览图（需要 Pillow 和 `rsvg-convert`）。

## 素材目录

| 目录 | 内容 |
| --- | --- |
| `素材/01-支出/` | 支出分类 SVG 和 PNG |
| `素材/02-收入/` | 收入分类 SVG 和 PNG |
| `素材/03-支出页面素材/` | 12 张分类卡片、顶部横幅、两张插画及男女变体；另有 `页面预览.png` |
| `素材/04-功能页面背景/` | 存钱计划、资产页和手机个人主页背景 |
| `素材/05-帐本封面/` | 无文字的帐本封面 SVG 和 PNG |

支出页面图片共 17 张，不含分类名称或金额。卡片底部留有浅色文字区，供页面叠加状态和金额；图片与参考布局中的区块等比例，尺寸为其 4 倍。`子女支出(女/男).png` 和 `左侧插画(女/男).png` 可按需要选用。运行 `python3 scripts/generate_page_assets.py` 可重建图片和布局预览。

功能页面背景均不含文字，供页面自行叠加信息。运行 `python3 scripts/generate_feature_backgrounds.py` 可重建：

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `存钱计划.png` | 1500 × 500 | 存钱计划顶部横幅，左侧留给白色数字 |
| `资产.png` | 1500 × 500 | 资产页顶部横幅，左侧留给深色数字 |
| `个人主页.png` | 2240 × 1268 | 手机个人主页顶部背景，左侧留给头像和白色标题 |

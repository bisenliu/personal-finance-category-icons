# 支出页面图片素材

本目录包含截图中 12 张支出分类卡片图片、顶部横幅和两张装饰插画，并为子女卡片与左侧插画各增加一张男版，共 17 张。图片不含分类名称或金额，供页面单独叠加文字。素材采用现有分类图标的造型和主题色，尺寸为截图对应图片区块的 4 倍，宽高比保持一致。

分类卡片底部保留浅色文字区，供页面叠加状态和金额；不要将金额写入图片。

`子女支出(女/男).png` 和 `左侧插画(女/男).png` 可按使用者选择；对应分类图标见仓库根目录的 `预览-子女变体.png`。

`页面预览.png` 按原截图布局拼接分类图片。要重新生成，运行：

```sh
python3 scripts/generate_page_assets.py
```
